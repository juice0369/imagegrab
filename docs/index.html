图提取 ImageGrab

一个 Chrome 扩展：一键提取电商页面的图片，自动去重、把缩略图还原成原图，统一转成 PNG 批量下载。

下载插件 v1.0.0 查看安装步骤 →

当前版本 v1.0.0 · ZIP 压缩包 · 需要 Chrome 116 或更高 · 解压后「加载已解压的扩展程序」

  • 只读取当前页面 DOM 里真实存在的图片地址：不爬取、不遍历商品 ID、不绕过登录。
  • 图片只在本机处理，结果存在会话级临时存储里，浏览器重启即清空。
  • 统一转成 PNG 批量下载，跨域读不到时自动降级为原格式，不算失败。
  • 被过滤的图片也会列出来并写明原因，判断错了可以手动勾选下载。
界面展示

提取结果都在一个页面里核对与下载

结果页把缩略图、过滤原因、下载进度放在同一屏：默认勾选所有还没成功下载过的图片，被规则拦下的图片用灰色虚线卡片列出原因，误判的可以直接勾上一起下载。

核心功能

从点一下按钮，到拿到干净的 PNG

提取、去重、还原原图、转换、下载各司其职，出问题的环节都会在界面上说明原因。

一键提取整页图片

点一下按钮，扩展先滚动页面触发懒加载，再扫描页面里所有图片地址：<img>、srcset、内联样式里的背景图，以及同源 iframe。

缩略图还原成原图

按平台规则把 _400x400.jpg、_.webp 这类缩略图地址还原成原图地址；还原后的地址失效时，回退下载页面上真实存在的那个地址。

智能去重与过滤

去重会忽略尺寸后缀、埋点参数（spm、ali_trackid、utm_*）和同一 CDN 的不同子域；图标、logo、占位图、装饰区域、过小图片与长宽比异常的条目会被拦下。

统一转 PNG 批量下载

JPG、JPEG、WebP、GIF、BMP 都在离屏文档里用 Canvas 统一转成 PNG；文件名形如 商品图_001.png，编号在同一个会话里连续递增。

失败可见、可重试

跨域导致读不到像素时自动按原格式下载并标记「原格式」，不计入失败；确实失败的条目会标红写明原因，可以单张重试或只继续未完成的条目。

只在本机处理

不上传任何数据，不搭服务端代理，不保存密钥；提取结果只写入会话级临时存储，浏览器重启、扩展重载或结果页关闭即清理。

支持的网站

这些域名下的页面都能用

能不能提取只取决于页面上有没有图片，跟页面类型无关：首页、搜索页、列表页、详情页都会出现「获取图片」按钮。

  • 淘宝 item.taobao.com www.taobao.com s.taobao.com 支持
  • 天猫 detail.tmall.com www.tmall.com 支持
  • 京东 item.jd.com item.m.jd.com www.jd.com search.jd.com 支持
  • 拼多多 mobile.yangkeduo.com 支持
  • 拼多多商家后台 mms.pinduoduo.com 支持
  • 本地测试页 localhost 127.0.0.1 仅开发测试

不在列表里的站点不会注入内容脚本，页面上不会出现按钮（工具栏图标仍可打开最近一次结果页）。平台换域名时，把新域名加进 PLATFORMS 的 hostPattern 与 manifest.json 的 matches 即可，通常只需要改这两个地方。

安装步骤

下载 → 解压 → 加载已解压的扩展程序

这个插件没有上架 Chrome 应用商店，需要手动加载。整个过程大约一分钟，不需要开发者工具链，也不需要 npm install。

  1. 1

    下载压缩包

    点击页面上的 「下载插件 v1.0.0」，得到 ImageGrab-v1.0.0.zip。

  2. 2

    解压 ZIP

    右键压缩包 → 解压到任意目录（例如桌面）。解压后会得到一个 ImageGrab-v1.0.0 文件夹，里面直接就是 manifest.json、src/ 和 assets/。

    必须解压：Chrome 不能直接加载 ZIP，第 5 步选的是解压出来的文件夹。
  3. 3

    打开扩展程序页面

    在 Chrome 地址栏输入 chrome://extensions 并回车。

  4. 4

    打开右上角的「开发者模式」

    开启后左上角会出现「加载已解压的扩展程序」按钮。

  5. 5

    选择解压出来的文件夹

    点击「加载已解压的扩展程序」，选中第 2 步解压出来的 ImageGrab-v1.0.0 文件夹（也就是包含 manifest.json 的那一层）。

    • 加载成功后列表里会出现「图提取 ImageGrab」。
    • 建议固定到工具栏：点地址栏右侧的拼图图标 → 固定「图提取 ImageGrab」。
    • 如果提示清单文件缺失，说明选错了层级，改选含 manifest.json 的目录。
使用步骤

从商品页到下载目录

按钮会记住你拖动后的位置；工具栏图标则等价于「打开最近一次提取结果」。

  1. 1

    打开一个受支持的电商页面

    商品详情页、首页、搜索页、列表页都可以，只要页面上有图片。

  2. 2

    点击右下角的「获取图片」

    悬浮按钮可以拖动，位置会被记住。点击后扩展会先滚动页面触发懒加载，再扫描图片、补全地址、还原原图、去重过滤。

    • 有结果时自动打开结果页标签。
    • 一张都没提取到时，状态卡片会按原因展开过滤明细。
  3. 3

    在结果页里核对与勾选

    默认已经勾选所有还没成功下载过的图片。用「全选 / 反选 / 取消选择 / 选中失败项」批量调整，或用「范围 / 尺寸 / 状态」筛选列表；筛选只影响显示，不影响已勾选项。

    • 被过滤的图片是灰色虚线卡片，徽标写明原因，默认不勾选，误判的可手动勾上。
    • 点卡片或勾选框都能切换选中状态。
  4. 4

    点「下载选中」开始批量下载

    每张卡片右下角也有「单张下载」。点「取消任务」会停下还没开始的条目，已经开始的不打断，避免留下半截文件；中断后可以点「继续下载」只跑未完成与失败的条目。

  5. 5

    在下载目录里取用

    文件默认落在浏览器的下载目录，统一转成 PNG，文件名形如 商品图_001.png；编号在同一个会话里连续递增，结果页顶部会显示「下一个文件名」。

    • 跨域读不到像素的条目会按原格式下载，并标记「原格式」。
    • 确实失败的条目会标红写明原因，并有「重试」。
常见问题

安装和使用时最常遇到的情况

照着上面的安装步骤走一遍，这些问题基本都不会出现。

下载下来的 ZIP 能直接「加载已解压的扩展程序」吗？

不能。Chrome 只接受文件夹，所以必须先解压 ZIP，然后在 chrome://extensions 里选择解压出来的那个文件夹（含 manifest.json 的那一层）。直接选 ZIP 文件时选择框根本不会让你确认。

为什么要求 Chrome 116 或更高？

插件用到 chrome.runtime.getContexts 和离屏文档（Offscreen Document）来在后台把图片转成 PNG，这两个能力在 Chrome 116 才齐全。更低版本的 Chrome 里转换环节会失败。

会不会把我的图片或账号信息上传到服务器？

不会。扩展不搭服务端，也没有任何上传逻辑：图片只在本机用 Canvas 处理。它不会爬取、不遍历商品 ID、不绕过登录与鉴权，提取结果只写入 chrome.storage.session（会话级临时存储），浏览器重启即清空。

为什么提取到的图片比我预期的少？

多半是被过滤规则拦下了。结果页顶部会写明「扫描到 N 个地址，保留 M 张，过滤掉 K 张」，被过滤的图片也会以灰色虚线卡片列出来，徽标写明原因：占位图、图标/广告、装饰区域、尺寸过小、长宽比异常、重复。

如果确认是误判，直接勾上那张卡片，和正常图片一起下载即可。

为什么下载下来的图片标记成「原格式」而不是 PNG？

说明这张图跨域了：虽然能下载，但画布读不到像素，没法转 PNG。这时扩展会按原格式下载并标注「原格式」，不计入失败。批量结束的汇总里也会单独列出「原格式 N 张（不算失败）」。

批量下载到一半提示「与扩展后台的连接已断开」怎么办？

这是浏览器的 Service Worker 被回收导致的，任务会中断但进度不丢。刷新结果页后点「继续下载」，就只会重跑未完成与失败的条目。

页面右下角没有出现「获取图片」按钮？

按顺序排查这几项：

  • 当前域名是否在支持列表里（面板与内容脚本只注入列表内的站点）。
  • 在 chrome://extensions 里确认扩展已启用、没有报错。
  • 刚装好或刚更新过扩展时，刷新一下目标页面。
  • 如果是平台换了域名，把新域名加进 PLATFORMS 的 hostPattern 与 manifest.json 的 matches。
支持 Edge、Firefox 或其它浏览器吗？

目前只针对 Chrome 开发与验证。其它 Chromium 内核浏览器（Edge、Brave 等）在 chrome://extensions 对应页面里大概率也能加载，但没有做过测试；Firefox 的扩展 API 与清单格式差异较大，不能直接使用。

点击下载按钮没有反应？

可以这样处理：

  • 检查浏览器是否拦截了本站的自动下载，允许后重试。
  • 直接在地址栏打开相对地址 downloads/ImageGrab-v1.0.0.zip。
  • 如果是从 GitHub Pages 打开本站，请确认 downloads 目录已随站点一起发布。
